What is HTML?
HTML:
Html stands for HyperText Markup Language and is the standard markup language used to create and structure the framework of web
What is CSS?
CSS:
CSS stands for Cascading Style Sheets. It is a style sheet language used to describe the presentation, design, and layout of a document written in a markup language like HTML.
What is Web Develement?
Web Develement:
Web development is the work needed to build, create, and run websites and web apps on the internet.
